# Reposit+

Reposit+ é um aplicativo para organizar atividades, anotações e arquivos escolares em um só lugar.

A ideia do projeto é facilitar a organização de conteúdos sem precisar separar tudo entre pastas, aplicativos de notas e outros programas.

## Aviso sobre a versão 0.7.0

A versão 0.7.0 pode parecer um retrocesso em alguns pontos, mas essa mudança foi planejada como parte do amadurecimento do projeto.

Algumas funções foram removidas temporariamente para que eu pudesse focar na estabilidade, desempenho e nas funções que realmente estavam funcionando bem.

O Mural foi removido porque o sistema de conexão P2P por IP ainda poderia causar problemas de conexão e, em alguns casos, gerar um consumo inesperado de recursos da máquina.

O sistema de envio por e-mail também foi removido por enquanto. A implementação ainda dependia de uma solução adequada para autenticação e envio, e não encontrei uma alternativa que eu considerasse boa o suficiente para manter no aplicativo.

Em vez de deixar funções incompletas ou instáveis apenas para aumentar a quantidade de recursos, preferi removê-las e concentrar o desenvolvimento no restante do Reposit+.

A versão 0.7.0 recebeu várias otimizações, correções e melhorias nas animações, interface e funcionamento geral do aplicativo.

Essa versão também começa a preparar a base para uma atualização maior planejada para a versão 1.0.0.

Durante os próximos dias, versões de hotfix poderão ser lançadas para corrigir bugs e outros problemas encontrados na 0.7.0.

## Funções

* Criar, editar e excluir anotações
* Organizar atividades e arquivos
* Editor de texto com opções de formatação
* Adicionar imagens, GIFs, áudios e arquivos às anotações
* Organizar conteúdos utilizando tags
* Acompanhar atividades e prazos
* Marcar atividades como concluídas
* Fixar atividades importantes
* Trabalhar com múltiplas anotações em abas
* Quick Mode para acesso rápido
* Temas e configurações de aparência
* Salvamento automático
* Interface com animações
* Armazenamento local dos dados
* Funcionamento sem necessidade de conexão com a internet
* Otimizações para reduzir o uso de memória e processamento

## Instalação

Baixe a versão mais recente pela página de **Releases** do repositório.

O **Setup** instala o Reposit+ normalmente no Windows e prepara os arquivos necessários para o funcionamento do aplicativo.

A versão **Portable** pode ser executada sem instalação.

As versões distribuídas do Reposit+ já incluem o necessário para funcionar. Não é preciso instalar Python ou configurar dependências manualmente.

## Desenvolvimento

O Reposit+ continua em desenvolvimento.

Funções podem ser modificadas, substituídas ou removidas conforme o projeto evolui. A prioridade é manter o aplicativo simples, estável, leve e útil, em vez de manter recursos que ainda não funcionam da maneira esperada.

A versão 0.7.0 representa principalmente uma etapa de estabilização e preparação do projeto para versões futuras.

Problemas encontrados durante o uso e sugestões de melhorias podem ser enviados pela área de **Issues** do repositório.
