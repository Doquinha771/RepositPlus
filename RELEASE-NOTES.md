# Reposit+ 0.7.0

A versão 0.7.0 representa uma etapa de amadurecimento do Reposit+.

Apesar da remoção de algumas funções, o objetivo desta versão foi reduzir a complexidade do projeto, corrigir problemas acumulados e melhorar principalmente a estabilidade, desempenho e experiência geral do aplicativo.

## Principais mudanças

* Remoção temporária do Mural
* Remoção temporária do sistema de envio por e-mail
* Diversas otimizações de desempenho
* Melhor gerenciamento do uso de memória
* Redução do consumo de recursos em segundo plano
* Melhorias nas animações e transições da interface
* Ajustes no Quick Mode
* Melhorias gerais na estabilidade
* Correções de bugs encontrados nas versões anteriores
* Pequenos ajustes de interface e usabilidade
* Limpeza e simplificação de partes internas do projeto
* Preparação da base do aplicativo para futuras atualizações

## Sobre as funções removidas

O Mural foi removido porque o funcionamento através de conexões P2P por IP ainda poderia apresentar problemas e, em algumas situações, causar um consumo inesperado de recursos.

O envio por e-mail também foi retirado temporariamente. Ainda não encontrei uma solução de autenticação e envio que seja adequada para o projeto sem depender de uma implementação que considero incompleta ou problemática.

Essas funções poderão retornar futuramente caso seja encontrada uma forma melhor e mais estável de implementá-las.

## Próximos passos

A 0.7.0 serve como uma nova base para o desenvolvimento do Reposit+.

Nos próximos dias poderão ser lançados hotfixes para corrigir bugs e problemas encontrados nesta versão.

O próximo grande objetivo do projeto é a versão **1.0.0**, que deverá representar uma atualização maior do Reposit+ e aproveitar a base mais estável construída nesta versão.

Obrigado por testar e acompanhar o desenvolvimento do Reposit+.
