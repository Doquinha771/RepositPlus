# Changelog

Todas as mudanças importantes do Reposit+ serão registradas neste arquivo.

## 0.5.0

- Melhorias no editor de anotações
- Suporte a imagens e GIFs dentro das anotações
- Suporte a arquivos e áudios
- Mais opções de formatação de texto
- Melhorias no sistema de tags
- Redimensionamento de imagens
- Melhorias no Validador de Atividades
- Atividades podem ser fixadas e marcadas como concluídas
- Indicadores de prazo para atividades
- Melhorias no mural
- Melhorias no perfil e configurações
- Novos temas
- Melhorias no Quick Mode
- Quick Mode pode ser fechado com Esc
- Sidebar recolhível
- Melhorias gerais na interface
- Melhorias de desempenho
- Correções de bugs

## 0.1.0

- Primeira versão do Reposit+
- Sistema inicial de anotações
- Organização de atividades
- Mural
- Compartilhamento de atividades
- Sistema de e-mail
- Configurações básicas
- Interface inicial do aplicativo
